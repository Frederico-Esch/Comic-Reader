# Commands

## Utilities
- O -> Opens comic
- P -> Shows/Hides page number
- R -> Rotates between Horizontal and Vertical Viewing
- = -> Best fit zoom for page

## Movements

- 0                                              -> Goes all the way up
- Space                                          -> Passes page
- J | Arrow Down | Scroll Down | Drag mouse down -> Scroll page down
- K | Arrow Up   | Scroll Up   | Drag mouse up   -> Scroll page up
- L | Drag mouse right                           -> scroll page right
- H | Drag mouse left                            -> scroll page left
- +/- | Left-Ctrl + Scroll Wheel                 -> Zoom


## Tips

It only handles CBZ. To convert from CBR to CBZ simply extract the rar (CBR are rar files) and compress it again as a zip file
